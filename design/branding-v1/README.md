# Photo Cleaner brand assets - concept v1

Purple overlapping photo cards with a precision glint: duplicates becoming a cleaner library.

- icon-128.png: Chrome Web Store icon, transparent 128 x 128 canvas; artwork fits within 96 x 96.
- icon-16/32/48/64/256/512.png: PNG icon exports for toolbar, extension and other placements.
- logo-light.png: horizontal wordmark on transparency, charcoal lettering for LIGHT backgrounds.
- store-thumbnail-440x280.png: opaque RGB promotional tile for the Chrome Web Store.
- *-master.png: original high-resolution raster artwork.

Palette: rich purple, lavender, white, and deep charcoal. The logo master and icon master were generated independently from the same reference; use the standalone icon as the canonical mark for implementation. These are raster PNG assets, not SVG/vector source.

Generated artwork; exported with high-quality resampling. No existing product assets or manifest entries were replaced.
Chrome requirements: https://developer.chrome.com/docs/webstore/images
